# ManaBook AI — Advanced V2 Prototype

Mobile-first prototype for the Interactive AI Digital Textbook concept.

Included:
- State/class/medium/subject/book selection
- Real-book style reader
- Page tools: highlight, sketch, bookmark, note
- Page Pull interaction
- Lesson Comes Alive mode
- Story / Teacher / Simple / Cinematic modes
- Voice demo using browser speech synthesis
- Explain More
- Language selector placeholder
- AI Q&A placeholder
- Practice quiz
- Revision / highlights
- AI tools
- Parent/teacher dashboard placeholder
- Bottom mobile navigation

This uses an original sample lesson. Official textbook pages/content should only be integrated after the required authorization/licensing.

Deploy:
1. Upload `index.html` to GitHub.
2. Import the repo into Vercel.
3. Select a static/no-framework deployment.
